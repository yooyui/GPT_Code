用一张浅色入口页 先把定位说清楚

Welcome Layer / スタートページ

这个示例展示了 Landing / Home 配方：更强的 hero、更少的导航、更直接的速读结构， 适合做文档入口页、协议入口页、服务说明入口页。

ENTRY 首页优先讲定位 SCAN 先看到重点，再决定要不要细读 SOFT 轻色彩和轻动效一起工作
速读摘要 Quick Scan
Purpose 作为入口页起稿
Entry

这一页最重要的是先解释你是谁、这页讲什么、用户接下来去哪。

Weight Hero 权重最高
Hero First

用户一进来就该知道主题，而不是先被一堆细节淹没。

Modules 卡片够用即可
Lean

入口页不需要把所有模块都铺满，能讲清定位和边界就够了。

Deploy 相对路径友好
Portable

适合作为静态入口页直接预览，也适合作为多页面站的起点。

推荐在第二屏用 cards 展开范围、费用、风险、隐私、免责等核心信息。

Landing 页常见三种信息

建议把首页信息压缩成少量高价值卡片，而不是所有说明一次性写完。

✨
01 / Position

这是什么

用一句清楚的说明，告诉用户当前页面是服务入口、协议入口，还是一个说明页集合的首页。

🧭
02 / Scope

这页涵盖什么

把费用、边界、更新、协议、隐私这些信息分别放到对应页面，而不是全部塞在 hero 里。

🫧
03 / Mood

为什么看起来要轻

说明页也可以友好、温和、可进入，但这种轻盈要服务信息结构，而不是喧宾夺主。

Landing sample note

如果你只是需要一个入口页，这个示例已经足够起稿。后续再按需要拆出 About、Announcement、Privacy 或 Agreement 页面即可。
