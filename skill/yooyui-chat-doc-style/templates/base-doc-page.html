Doc Rhythm / ページ設計

这是 skill 自带的基础页面模板。你可以直接复制它作为新页面起点，再按内容任务保留、 删除或替换其中的模块。

Position 一页即可起稿
Starter

适合做 landing、about、公告页、协议页和隐私页的第一版骨架。

Theme 浅色玻璃拟态
Pastel

高饱和强调色只用于少数节点，正文保持克制稳定。

Modules 可裁剪组合
Flexible

不是所有模块都必须保留，按页面任务删减即可。

Links 优先相对路径
Portable

静态预览、部署和后续分享都会更轻松。

起稿时先写主题、边界、适用人群，再往下展开结构，不要一上来堆满长段正文。
Tone 明亮，但不轻浮

背景轻、信息稳、重点清楚，适合说明页和规则页。

Structure 先摘要，再细化

Hero、摘要模块、细节模块、结论块，这套节奏尽量保持稳定。

Output 从模板到页面家族

先做一页能跑，再抽成可共享主题和多页面系统。

三段式信息展开

如果你不知道正文从哪里开始，可以先用三个 detail panel 把定位、边界和下一步拆开。

Why

为什么是这页

用一句话解释页面存在的目的，让用户知道自己为什么要继续往下读。

What

这页讲什么

给出主题边界，不要让用户读到一半才发现内容和预期不同。

Next

接下来去哪

用导航、锚点或底部链接，让页面的后续路径更清晰。

时间线或阶段线

公告页、隐私页、更新页、流程页都可以借用这一块做分阶段说明。

Step 01

先交代背景

用短段落说明场景、定位和阅读入口。

Step 02

再拆解重点

把复杂说明分配给时间线、卡片或 detail grid，不要直接变成长墙。

Step 03

最后给出提醒

收尾时用 quote-box 或 notice 给出立场、风险和边界。

卡片模块

每张卡尽量只讲一个核心点，这样页面会更容易扫读。

01
Core / Topic

一个卡片只放一个重点

把说明页拆成多个独立信息块，而不是把所有内容压到一屏里。

02
Accent / Highlight

强调色只用在少数位置

不要让整页都在抢眼，重点永远只服务于结构和阅读路径。

03
Scale / Family

先做一页，再抽成家族

当页面类型变多时，把公共样式收进共享主题文件，避免每页自成体系。

这套模板不是要求所有页面长得完全一样，而是帮助你在不同页面任务之间，保持同一种轻盈、 可扫读、可扩展的文档节奏。

Portable starter note

如果你正在一个没有现成页面家族的仓库里工作，先复制这张页面和基础 CSS；等第二页、第三页出现时， 再把通用部分回收到共享主题文件里。
